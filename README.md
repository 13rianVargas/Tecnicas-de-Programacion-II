# 📚 Técnicas de Programación II

Repositorio de proyectos y ejercicios desarrollados para la asignatura **Técnicas de Programación II** de la Fundación Universitaria Konrad Lorenz.

## 📋 Descripción

Este repositorio contiene una colección de proyectos y ejercicios prácticos en Java que cubren conceptos fundamentales de programación orientada a objetos, incluyendo:

- Interfaces gráficas de usuario (GUI) con Java Swing
- Patrón de diseño Modelo-Vista-Controlador (MVC)
- Herencia y polimorfismo
- Clases abstractas e interfaces
- Manejo de excepciones
- Persistencia de datos
- Operaciones CRUD

## 🚀 Proyectos Principales

### 🎓 CRUD Estudiantes
Sistema de gestión de estudiantes que permite crear, leer, actualizar y eliminar registros de estudiantes universitarios. Implementa el patrón MVC y una interfaz gráfica con Java Swing.

### 🚗 Parqueadero Konrad Lorenz
Sistema de gestión de parqueadero que calcula tarifas para diferentes tipos de vehículos (bicicletas, motos y carros), incluyendo cálculo de IVA y redondeo de precios.

### ⚽ Liga Postobón
Simulador de liga de fútbol que modela jugadores, árbitros, directores técnicos y aficionados utilizando herencia y clases abstractas.

### 🍽️ Crepes And Waffles
Sistema para gestión de pedidos de un restaurante, implementando el patrón MVC.

### 📒 Mi Primera Agenda
Aplicación de agenda de contactos para almacenar y gestionar información de contactos.

### 📐 Actividad GUI
Conversor de medidas con interfaz gráfica que permite convertir valores entre diferentes unidades de medida.

## 🔧 Instalación y Uso

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/13rianVargas/Tecnicas-de-Programacion-II.git
   ```

2. **Importar en Eclipse:**
   - Abrir Eclipse
   - File → Import → General → Existing Projects into Workspace
   - Seleccionar la carpeta del repositorio
   - Seleccionar los proyectos a importar

3. **Importar en NetBeans:**
   - Abrir NetBeans
   - File → Open Project
   - Navegar a la carpeta del repositorio
   - Seleccionar los proyectos a importar

4. **Ejecutar un proyecto:**
   - Localizar la clase `AplMain.java` o la clase principal del proyecto
   - Ejecutar como aplicación Java
